# Student Management System

## About the Project
The Student Management System is a C++ application that manages student records efficiently. It allows users to add, display, search, update, and delete records, calculate grades, and store data using file handling.

## Features
- Add student records
- Display all students
- Search students by roll number
- Update student details
- Delete student records
- Calculate student grades
- Save and load records using file handling

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- File Handling

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Compile the program:
   `g++ -std=c++14 student.cpp -o student`
4. Run the program:
   `.\student`
